# Maths-v2

A short creative web experiment titled “Maths is not romantic.” Its single-page presentation combines mathematical imagery with a simple play and replay interaction.

## Preview locally

Open `index.html` in a modern browser, or serve the page over HTTP:

    python -m http.server 8000

Visit http://localhost:8000.

## Making changes

The page and its interaction are defined in `index.html`, with `pro.mp3` included as a local audio asset. Keep the audio path intact if replacing the file. Mobile browsers may require a user gesture before sound can play.
